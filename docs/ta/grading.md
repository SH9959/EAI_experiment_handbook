# 助教：课堂验收

根据课程实际安排的部分验收。查看学生自己的输入、完整日志和结果；未执行的部分及原因单列。

| 实验 | 检查内容 |
|---|---|
| 对话与多模态 | 文本回答与问题相关；图像问答随输入变化；BLIP 描述与后续回答均保留；转写与录音一致，合成音频可播放。集成部分能追踪同轮输入与中间文件 |
| AnyGrasp | 点云尺度和坐标系正确；候选抓取、仿真抓取、实机抓取分别记录；完成抓取须有物体离开支撑面后的画面和实际状态 |
| ALFWorld | 保存任务、动作、环境反馈及结束状态；区分文字和视觉任务，以及人工与模型动作来源 |
| ALFRED | 报告实际任务数、SR/GC/PLW SR/PLW GC，并展示一条失败轨迹及其原因 |
| AI2THOR | 保存观察、动作、执行反馈和最终目标检查；模型部分还须保存真实模型回答，不能用预设动作代替 |
| VirtualHome | 逐步反馈通过，目标三文鱼在指定冰箱内、门关闭、未持握；反馈失败或最终图缺失时不能判任务通过。模型规划另查来源和原始回答 |
| 方块重排/汉诺塔 | 计划合法；每次实际搬运后重新观测；状态记录支持动作完成和最终目标，不能只验最终照片 |
| iGibson | 场景和资产版本、起点/目标、控制方法及实际回合记录；区分到达目标、超时和其他终止，再计算成功率与比较结果 |
| ACT 仿真 | 示教数量、字段与画面；训练参数、损失及 checkpoint；实际评估回合数、成功数、平均回报和失败录像。回合曾达到奖励 4 与末步仍为 4 分开统计 |
| ACT CPU 单输入 | 清单中的模型/统计/参考输入匹配；输出有限且形状正确，与参考满足指定容差。仅此结果不算完成采集、训练或仿真评估 |
| ACT 实机 | 数据包含三路相机与关节状态，训练数据与推理配置一致；推理由模型控制从臂，逐次人工记录任务结果 |

文件生成、loss 下降、安装成功或退出码 0 都不能单独代替任务结果。学生应能指出第一处失败的输入、动作或反馈；实验未成功时，完整且可追溯的失败记录仍需保留。

历史参考结果和未实测项目见[实测范围与资源缺项](validation-status.md)。
