# 学生实验：从这里开始

## 实验流程

1. **确认实验目标与条件**：根据课程安排选择实验，核对目标、环境和完成标准。
2. **配置实验环境**：按实验页配置 Conda / ROS 及依赖；依赖不同的实验分别配置环境。
3. **运行样例与任务**：先运行官方或课程样例，再按实验步骤调整输入和任务。缺少模型、工程或设备时，记录缺项。
4. **检查并保存结果**：按完成标准核对输出，保存命令、环境版本、日志和图像或音频；失败时记录报错与定位过程。

## 脚本与验证说明

部分实验配有手册侧辅助脚本，代码来源和适用版本见各实验页。`CHECK ONLY`、`FORMAT_ONLY`、`PLAN_ONLY` 及离线测试仅检查指定的输入、格式或辅助逻辑，不能替代 API、模型、仿真和设备的真实运行。修订依据与历次验证结果保存在各实验页链接的检查记录中。

## 章节入口

| 章节 | 实验 | 推荐起点 |

!!! warning "实机实验"
    涉及机械臂、夹爪、相机、CAN/USB、ROS 的实验必须在助教或教师确认设备状态后进行。首次运行时使用低速、分步执行，并保持急停可用。
