# 学生实验：从这里开始

这本手册不是教材正文的重复版，而是把教材中的实验内容整理成可以直接执行的流程。教材负责解释“为什么”，这里重点告诉你“现在该做什么”。实验范围严格对应教材 **3.4、4.4、5.7**。

## 你的标准实验流程

<div class="grid cards" markdown>

- **1. 找到本次实验**

  根据老师布置的章节进入对应页面，先看“你将完成什么”和“成功判据”。

- **2. 单独创建环境**

  按该实验页面给出的 Conda / ROS 环境配置，不要复用其他实验环境。

- **3. 先跑最小例程**

  先确认官方或课程 demo 能运行，再修改任务、Prompt、模型或机器人动作。

- **4. 再做完整任务**

  保存关键日志、结果图像或视频，出现错误时先判断是环境、模型、仿真器还是机器人执行问题。

</div>

## 章节入口

| 章节 | 实验 | 推荐起点 |
|---|---|---|
| 3.4 具身感知 | 人机对话 / 语音 / 抓取 | 没有 GPU 也可先做大模型 API 调用 |
| 4.4 具身推理 | ALFWorld / ALFRED / AI2THOR / VirtualHome / 实机规划 / iGibson | 先做 ALFWorld，再做 AI2THOR |
| 5.7 具身执行 | ACT 仿真 / cobot-magic 实机 | 必须先完成仿真，再接实机 |

!!! warning "实机实验"
    涉及机械臂、夹爪、相机、CAN/USB、ROS 的实验必须在助教或教师确认设备状态后进行。首次运行时使用低速、分步执行，并保持急停可用。
