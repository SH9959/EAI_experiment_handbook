# 学生实验

先完成[代码与终端准备](setup.md)，再按课程安排选择实验。开始安装前，查看[所需资源](verification.md)，确认模型、场景或设备是否齐全。

| 教材章节 | 实验 | 要完成的操作 |
|---|---|---|
| 3.4.1—3.4.3 | [人机对话与多模态交互](ch3-dialogue.md) | 文本问答、图像问答、语音识别与合成，再连接各模块 |
| 3.4.4 | [AnyGrasp 抓取](ch3-grasp.md) | 生成抓取候选，在仿真中夹起方块，再进行实机抓取 |
| 4.4.1 | [仿真任务规划](ch4-planning.md) | 运行指定环境中的任务，检查动作和最终目标 |
| 4.4.2—4.4.3 | [实机任务规划](ch4-real.md) | 识别场景、生成合法计划、逐步搬运，完成方块重排或汉诺塔 |
| 4.4.4 | [iGibson 导航](ch4-navigation.md) | 加载场景，让机器人到达目标，比较两种控制方法 |
| 5.7.1 | [ACT 模仿学习](ch5-imitation.md) | 检查示教、训练策略、评估方块传递；无 GPU 时可先做已有模型的 CPU 单输入检查 |

每项实验按“目标 → 环境 → 操作 → 结果 → 排错”的顺序阅读。执行命令后先检查紧随其后的预期结果，再继续下一步。

保存自己使用的命令、输入、环境版本、结果和失败日志。遇到缺失资源时，记下文件名、所需版本和停止的步骤，交给助教确认。
