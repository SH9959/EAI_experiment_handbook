# 第 4 章：实机任务规划

> 对应教材：**4.4.2 方块重排、4.4.3 汉诺塔**。

这两个实验的重点不是重新学习机械臂控制，而是把第 4 章的**高层规划**接到第 3 章的**视觉感知与抓取执行**上。

## 一、方块重排

### 任务

桌面上叠放红、黄、蓝三个方块。机器人取方块时必须满足：**先取上方方块，再取下方方块**。

### 教材所需模块

| 模块 | 作用 |
|---|---|
| RealSense | 获取 RGB / Depth |
| Qwen-VL | 识别桌面布局并生成文本场景描述 |
| Qwen-max | 根据规则生成动作规划；生成更明确的物体描述 |
| GroundingDINO | 根据描述在图像中定位目标物体 |
| AnyGrasp | 根据点云生成抓取候选位姿 |
| 机械臂 + 夹爪 | 执行抓取和放置 |

### 完整流程

```text
RGB-D 图像
   ↓
Qwen-VL：场景 → 文本描述
   ↓
Qwen-max：生成动作序列
   ↓
Qwen-max：生成目标物体的细粒度描述
   ↓
GroundingDINO：目标框
   ↓
裁剪/拼接 RGB-D → 点云
   ↓
AnyGrasp：抓取位姿
   ↓
位姿筛选
   ↓
机械臂抓取与放置
```

### 为什么要单独生成“物体描述”

教材给出的工程经验是：GroundingDINO 用“**位于黄色方块下方的红色方块**”这类带上下文的描述，往往比仅输入“红色方块”更容易获得准确框选。因此规划结果中的对象名称需要再转成适合视觉接地的描述。

### 执行前检查

- 目标框是否只覆盖目标方块；
- 深度图在目标区域是否有效；
- 点云是否在正确尺度和坐标系；
- 抓取姿态是否容易导致机械臂逆解极限；
- 夹爪接近方向是否会碰桌面或其他方块。

### 教材列出的典型问题

- **逆解结构限位：** 调整机器人初始姿态或改选抓取位姿；
- **移动过程碰撞：** 增加碰撞检测，或在实验摆放阶段主动留出安全空间；
- **方块滑落：** 在不损坏物体的前提下提高夹爪力度，并重新检查抓取姿态和物体表面。

## 二、汉诺塔

### 任务

把所有盘子从第 1 根柱子移动到第 3 根柱子，并始终满足：**大盘不能放在小盘上**。

### 实验流程

```text
摄像头图像
   ↓
Qwen-VL：识别三个柱子及每根柱子的盘子状态
   ↓
Qwen-max：Chain-of-Thought 规划
   ↓
把自然语言规划转成结构化动作，例如 (1)->(3)
   ↓
解析动作
   ↓
机械臂执行抓取和放置
```

教材建议汉诺塔优先使用**固定的柱子抓取/放置位姿**降低难度，而不是完全依赖 AnyGrasp 动态生成所有姿态。

### 推荐调试顺序

1. 不连接机械臂，只验证图像识别是否能正确读出盘子状态；
2. 只让大模型规划，检查每一步是否满足汉诺塔规则；
3. 把规划输出固定成 `source -> target` 格式并测试解析器；
4. 手动给定一条合法动作，让机械臂完成一次盘子搬运；
5. 最后才把“识别 → 规划 → 执行”闭环起来。

!!! danger "实机要求"
    这两个实验都需要助教先确认机械臂工作空间、桌面高度、夹爪力度和急停状态。大模型输出必须先经过格式与规则检查，再允许进入机器人执行层。
